工程化能力 ​

从 vite.config.ts 与 build/vite/ 可以看出，构建配置被按职责拆分，而不是全部堆在一个文件里：

  • 自动导入：unplugin-auto-import + unplugin-vue-components，减少重复的 import 语句；
  • 样式方案：UnoCSS 原子类 + Sass（virtual:uno.css 在 main.ts 中引入）；
  • 图标方案：@iconify/utils + vite-svg-loader，SVG 可直接当组件用；
  • 国际化：vue-i18n + @intlify/unplugin-vue-i18n，语言包位于 locales/modules；
  • 本地 Mock：vite-plugin-fake-server 配合 mock/ 目录；
  • 构建信息注入：vite.config.ts 通过 define.__APP_INFO__ 把包名、版本、依赖清单与构建时间戳注入运行时。

与 README 致谢清单的关系 ​

README 的特别鸣谢中列出了 Koa2、echarts、lodash、mitt、screenfull、phinx 等项目，它们反映了项目借鉴与致谢的整个生态；其中部分并未出现在当前 package.json 的直接依赖里。判断「能不能直接用某个 API」时，请以本章的依赖表为准。
