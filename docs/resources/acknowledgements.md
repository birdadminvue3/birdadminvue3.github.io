# 特别鸣谢与版权

## 特别鸣谢

以下为项目**实际使用**的技术与工具，未使用的库不再列出。

**框架与构建**

[Vue](https://github.com/vuejs/core)、[vue-router](https://github.com/vuejs/vue-router)、[Pinia](https://github.com/vuejs/pinia)、[Vite](https://github.com/vitejs/vite)、[TypeScript](https://github.com/microsoft/TypeScript)、[ESLint](https://github.com/eslint/eslint)

**UI 与样式**

[Element Plus](https://github.com/element-plus/element-plus)、[UnoCSS](https://github.com/unocss/unocss)、[Sass](https://github.com/sass/sass)、[nprogress](https://github.com/rstacruz/nprogress)

**数据与工具**

[Axios](https://github.com/axios/axios)、[vue-i18n](https://github.com/intlify/vue-i18n)、[VueUse](https://github.com/vueuse/vueuse)、[dayjs](https://github.com/iamkun/dayjs)、[vite-plugin-fake-server](https://github.com/condorheroblog/vite-plugin-fake-server)、[unplugin-auto-import](https://github.com/unplugin/unplugin-auto-import)、[unplugin-vue-components](https://github.com/unplugin/unplugin-vue-components)、[vite-svg-loader](https://github.com/jpkleemans/vite-svg-loader)

**参考项目**

[vue-pure-admin](https://github.com/pure-admin/vue-pure-admin)（布局与页签设计）、[cool-admin-vue](https://gitee.com/cool-team/cool-admin-vue)（国际化与主题切换特效）

**工具与支持**

[VSCode](https://code.visualstudio.com/) 提供开发工具支持，[WorkBuddy](https://www.workbuddy.cn/) 提供 AI 支持。
