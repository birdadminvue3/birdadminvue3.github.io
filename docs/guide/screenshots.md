# 页面预览

这一页集中展示项目仓库 `src/assets/readme/` 里的四张演示截图。它们对应本地启动后能看到的界面，取自当前仓库版本；规划中的功能不会出现在截图里，实际状态见[实现状态与路线图](/guide/roadmap)。

## 登录页

![BirdAdmin 登录页：渐变背景与居中登录卡片](/screenshots/login.png)

背景是粉色到橘色的渐变，底部有半透明方块装饰。登录卡片居中，包含 BirdAdmin 标识、版本号、`admin` 账号和已填写的密码；密码框右侧的眼睛图标用于显示 / 隐藏密码，右上角两个小图标分别切换主题和语言。

入口是 `http://localhost:9094/#/login`。运行方法见[快速开始](/guide/getting-started)，可用账号见[联系与演示](/resources/contact)。

## 控制台

![BirdAdmin 控制台：登录后的默认首页](/screenshots/dashboard.png)

控制台是登录后的默认落地页，左侧为深色导航，顶部是面包屑和多页签。截图里正文区域只有 `welcome` 占位文本，说明当前版本的控制台还没有填充业务卡片，这不是加载失败。

入口路径是 `/dashboard`，相关说明见[项目介绍](/guide/)。

## 菜单管理

![BirdAdmin 菜单管理：树形表格与行内操作](/screenshots/menu.png)

菜单管理页由通用 schema 渲染：左侧导航展开「系统管理」，顶部有面包屑与页签，主体是带搜索框和「新增」按钮的树形表格。表格按层级展示目录、菜单和按钮，列包含菜单名称、ID、路由路径、类型、权限标识、排序，行末是编辑和删除操作。

这里展示的是 `admin` 账号的视角。换成其他演示账号，左侧可见菜单会随角色变化，原理见[权限体系](/guide/permission)。

## 404 异常页

![BirdAdmin 404 页面：橙色提示图标与返回按钮](/screenshots/404.png)

404 页面用居中的橙色感叹号、大号数字和一行说明呈现，文案是「页面不存在，或当前账号无权访问」，下方有「返回首页」和「返回上一页」两个按钮。它同时承担路由兜底和无权限访问两种场景。

路由层面的注意事项写在[路由与多页签](/guide/routing)，同类页面还有 `/error/403` 和 `/error/500`。
