# 实现状态与路线图

这一页区分「现在就能跑」和「还在规划」，避免按旧资料去期待尚未实现的能力。内容来自项目 README 的「实现状态与路线图」。

## 已实现，可直接运行

**工程与构建**

Vite 7 + TypeScript + ESLint 10，`pnpm build` 先类型检查再打包；产物按 `static/js|css|imgs` 分目录，不生成 sourcemap，生产移除 `console`；dev 端构建信息插件输出文件数与体积。

**认证与路由守卫**

登录、token 持久化与过期判断、并发刷新订阅、401 重放、离线队列、重复请求取消、hash 路由兜底 404。

**RBAC**

菜单、角色、用户、部门、岗位、字典六类资源的 Mock CRUD，角色授权、用户分配角色、重置密码、状态切换，按用户权限下发动态路由与按钮权限。

**界面**

三种布局、暗黑主题与主题色、View Transition 切换特效、三种页签风格与完整页签操作、设置抽屉、水印、中英双语、动态页面标题、403 / 404 / 500 页面、权限演示页。

**验证情况**

`pnpm lint` 无错误、`pnpm build` 成功；dev 环境已对登录、刷新、22 项只读 / 权限断言与 33 项 CRUD / 授权断言做过接口级验证；生产包已确认无 Mock 凭据与 console 横幅。
