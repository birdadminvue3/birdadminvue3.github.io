一句话了解 ​

BirdAdmin 是一个基于 Vue3.x + ThinkPHP8 + TypeScript + Vite + Pinia + Element Plus 等流行技术栈的后台管理系统，支持自动注册路由、无限子级权限管理等，无需授权即可免费商用，帮助你实现快速开发。

本站内容整理自项目 README，并结合当前仓库 package.json、源码目录与配置文件补充了可验证的技术细节。

三分钟跑起来 ​

bash
# 1. 克隆项目
git clone https://gitee.com/web_akai/bird-admin.git

# 2. 进入项目目录
cd bird-admin

# 3. 全局安装 pnpm（已安装可跳过）
npm i -g pnpm

# 4. 安装依赖
pnpm install

# 5. 启动开发服务器（默认端口 9094）
pnpm run dev

# 6. 打包发布
pnpm run build

环境要求

项目 package.json 的 engines 要求 Node ^20.19.0 || >=22.12.0，推荐使用 pnpm。README 中「Node 16+ / 18+」的描述已不适用于当前版本，详见快速开始。
